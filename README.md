# ボート回収率ナビ

全国24場のボートレースについて、過去2年（2024-11-12〜2026-11-11、111,444レース）で作ったモデルの1着確率と、締切前の単勝オッズから期待値を計算して公開するサイト。現在は前向き検証中。

- `navi.py predict` 締切2〜25分前のレースの直前情報（展示タイム・風・波）と単勝オッズを取り、期待値を data/picks/YYYYMMDD.json に保存
- `navi.py settle` 前日までの競走成績を取り込み、狙い目の成績を data/record.json に集計
- `navi.py build` template.html から index.html を作る
- GitHub Actions（.github/workflows/update.yml）が JST 8:00〜21:59 に10分ごとに実行し、GitHub Pages に公開
- model.txt は 2年分すべてで学習した LightGBM。学習・検証のプログラムは秘書クロードちゃんプロジェクトの boat-navi/ にある

## 狙い目のルール
- 狙い目: 期待値（1着率×単勝オッズ）1.2以上 かつ 単勝10倍以下
- 参考: 期待値1.0以上
- オッズが出ている艇が5艇未満のときは印をつけない
- 過去の検証（最終オッズ使用）: 狙い目 126.8%、参考 118.1%。締切前のオッズで同じ結果が出るかを確認中
