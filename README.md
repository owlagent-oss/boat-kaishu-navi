# ボートレース ズレ偏差値ナビ（旧：ボート回収率ナビ）

## 方針変更（2026-11-23）
- 予想を売るサイトから、**過去データと独自指標「ズレ偏差値」を見せるデータサイト**に変更。収益は広告（AdSense の審査は要確認）＋noteメンバーシップなど
- 理由：11/12〜11/22の前向き検証（締切前のオッズで買った成績）は、単勝新ルール・セット買い・3連単4点/8点/ボックスのどれも回収率70%台で、控除後の平均（約75%）と同じだった
- 予想の印とその成績は「検証の記録」として残し、正直に公開する。「回収率○%」は宣伝に使わない
- 追加：`stats.py`（競走成績2年分から場ごとの1号艇1着率・3連単中央値・万舟率・コース別1着率を集計し data/stats.json に保存）、ページに「荒れランキング・平穏ランキング」「場ごとの基本データ」


全国24場のボートレースについて、過去2年（2024-11-12〜2026-11-11、111,444レース）で作ったモデルの1着確率と、締切前の単勝オッズから期待値を計算して公開するサイト。現在は前向き検証中。

- `navi.py predict` 締切2〜25分前のレースの直前情報（展示タイム・風・波）と単勝オッズを取り、期待値を data/picks/YYYYMMDD.json に保存
- `navi.py settle` 前日までの競走成績を取り込み、狙い目の成績を data/record.json に集計
- `navi.py build` template.html から index.html を作る
- GitHub Actions（.github/workflows/update.yml）が JST 8:00〜21:59 に10分ごとに実行し、GitHub Pages に公開
- model.txt は 2年分すべてで学習した LightGBM。学習・検証のプログラムは秘書クロードちゃんプロジェクトの boat-navi/ にある

## 狙い目のルール
- 狙い目: 期待値（1着率×単勝オッズ）1.2以上 かつ 単勝10倍以下
- 参考: 期待値1.0以上
- オッズが出ている艇が5艇未満のときは印をつけない
- 過去の検証（最終オッズ使用）: 狙い目 126.8%、参考 118.1%。締切前のオッズで同じ結果が出るかを確認中

## セット買い（検証中・2026-11-13 追加）
- 対象: ズレ偏差値63以上 かつ 単勝10倍以下の艇（ズレ偏差値＝3連単オッズから出した1着確率と単勝オッズのズレを偏差値にしたもの）
- 買い方: 単勝200円 ＋ その艇を1着に固定した3連単4点（3連単オッズの低い順）各100円。1セット600円
- 理由: 3連単だけでは過去約1万9,000レースのどの買い方も100%未満。単勝のズレは5年分で安定していたので、単勝を土台に3連単を組み合わせる。過去の検証（最終オッズ・初めて使う13,385レース）で 115.2%（90%幅107〜123%）。締切前のオッズで同じ結果になるかを確認中
- 成績: data/record.json の `set`（bets は100円単位＝1セット6、hits は的中セット数、ret は払戻の円）
